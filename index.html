Beginner's Guide

What is Bitcoin?

Bitcoin is a peer-to-peer electronic cash system. It is decentralized, open source, and gives users full control over their money. Visit bitcoin.org.

What is a bitcoin address and private key?

To receive bitcoin, you need a bitcoin address. To spend it, you need its private key. Keep your private key safe! Anyone with the private key can spend the coins. The address can be shared.

What is a paper wallet?

A paper wallet is a printed bitcoin address and private key. They are safe because they are offline, but be careful when generating them. See "Security tips".

What is a Legacy, SegWit, and Bech32 address?

Legacy addresses start with '1'. SegWit addresses (start with '3') use segregated witness for lower fees. Bech32 (start with 'bc1') is a newer native SegWit format.

What is Bip38 encryption?

Bip38 protects your paper wallet with a password. If stolen, funds are safe. If you forget the password, funds are permanently lost.

Security Tips

  • Only use paper wallets if you know exactly how they work. Mistakes result in permanent loss. See bitcoin wiki.
  • Always use an offline computer. Save this site (CTRL-S) and run it offline. Use incognito mode.
  • Use a bootable USB drive / "live cd" if possible.
  • Use a "dumb" / old printer. Smart printers may cache private keys.
  • Use a laser printer (water resistant) and keep wallets in a waterproof place.
  • Test with small amounts before sending large amounts. For BIP38 wallets, test decryption first.
  • Never use a paper wallet again after withdrawing from it.
Bip38 encryption allows you to protect your paper wallet with a password.

If you forget the password, there is absolutely no way to recover the wallet, meaning your funds will be PERMANENTLY LOST. Always test decryption first!

Note: Other applications may only support legacy addresses for BIP38. Use this site to decrypt SegWit addresses.
